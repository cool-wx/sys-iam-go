# Phase 3 Plan 01: Casbin enforcer 装配 + 双轨写路径 + requirePerm 即时生效

<objective>
**As a** 已登录的普通用户与管理员，**I want to** 功能权限由 Casbin RBAC 模型（用户→角色→perm 串）实时判定、管理员分配/回收权限后我的下一请求立即生效（无需重登录），**so that** 工控机上的 Go 版 IAM 拥有真正生效且即时更新的功能权限（显式区别于源系统"改权限需重登录"的登录快照语义）。

（2026-11-01 规划期语义等价转写为用户故事格式，原 ROADMAP goal：功能权限与数据权限真正生效，且权限变更即时生效（Casbin 策略热重载——用户决策，显式区别于源系统"改权限需重登录"的登录快照语义）；dataScope 部分在 Plan 03-02）

Purpose: 交付 PERM-01/02/04/05/06 的核心链路——enforcer 进程内单例装配（D-01..D-04）、纯 RBAC 模型（D-05/D-06）、四条写路径的双轨同步（D-13）、requirePerm 中间件与首条路由（D-08），并以"同一 token 下一请求生效"的集成断言锁定即时生效语义。

</objective>
